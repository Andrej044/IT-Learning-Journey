# Lab 02 - Active Directory Organizational Units

## Objective

Created a dedicated IT Organizational Unit to separate IT staff from other departments. 
This will allow department - specific Group Policies and delegated administration in future labs.

---

## Environment

- Host OS: Windows 11
- Hypervisor: Oracle VirtualBox 7.2.12
- Server OS: Windows Server 2022
- Domain: bt.local
- Domain Controller: BT-DC01

---

## Organizational Units Created

- Administration
- IT
- HR
- Finance
- Sales
- Servers
- Workstations

---

## Why use OU?

Organizational Units allow administrators to:

- Organize Active Directory objects
- Apply Group Policy
- Delegate administration
- Simplify management
